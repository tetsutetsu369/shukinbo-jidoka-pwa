# 出勤簿自動化 - フロントエンド

LINEのトーク履歴から勤務時間を自動抽出し、Googleスプレッドシートの出勤簿に反映するアプリのフロントエンド（PWA）。

バックエンド（AI 呼び出し・スプレッドシート書き込み）はGoogle Apps Scriptで別途運用しており、このリポジトリには含まれない。

AI の呼び出しは AI Gateway（Cloudflare Workers）経由で、モデルは Gateway 側が選択する
（Gemini 系を一次候補とし、失敗時は順にフォールバックする）。このため画面の文言は
特定のモデル名を出さず「AI」と表記している。

## 初回利用時

サイトを開くとアクセスコードの入力を求められる。管理者から共有されたコードを入力すること（ブラウザのlocalStorageに保存され、以後は再入力不要）。
